# T071-PS-017: Savings Account Interest, Charges and Sweep-In FD Engine

## Project Overview
This project implements a command-file-driven core banking engine using Python 3.13. It manages savings accounts, processes transactions, calculates interest and charges, and supports automatic sweep-in and sweep-out of linked fixed deposits.

## Team Members
- Laasya S
- Lavanya V

## Main Features
- Savings account creation and management
- Credits, debits and transaction validation
- Daily balance-based interest calculations
- Minimum Average Balance (MAB) penalties
- ATM, branch and cheque transaction charges
- Automatic fixed deposit creation and breakage
- Overdraft and dormancy management
- Standing instructions and lien recovery
- Passbook generation and monthly charge summaries
